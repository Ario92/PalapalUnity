# Project Structure Validator & Creator

This package helps teams maintain consistent folder structure and naming conventions.

## Highlights

- **Validate All**: Tools → Project Structure Validator & Creator → Validate All — validates all configured folders and shows progress.
- **Validate Folder**: Right-click a folder in the Project window and choose `Project Structure Validator & Creator/Validate Folder` to validate that folder; the menu is always visible and will show an informational dialog if a non-folder is selected.
- **Optional Issue Console integration**: When the optional `com.palapalco.issue-console` package is available, validator warnings may be reported to it via reflection. There is no hard dependency.

For usage and configuration, see the package documentation and examples.
